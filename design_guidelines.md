# Spectra 3D Hub - Design Guidelines

## Brand Identity
- **Name**: Spectra 3D Hub
- **Tagline**: "Turning ideas into high-quality 3D printed products"
- **Personality**: Precision, innovation, engineering, creativity
- **Visual Direction**: Futuristic deep-tech startup (not poster/brochure style)

## Color Palette & Theme
- **Base**: Dark theme foundation
- **Accents**: Neon cyan, electric blue, glowing accents
- **Treatment**: Subtle glows, tech-style borders, luminous effects

## Layout & Structure

### 1. Hero Section
- Full-screen viewport height
- Background: Looping muted video showing 3D printing/tech visuals
- Bold animated headline with brand name
- Subtext explaining services
- Dual CTAs: "Get Quote on WhatsApp" + "Explore Our Work"
- Buttons with blurred backgrounds when on video

### 2. Custom Cursor (Critical Feature)
- Small glowing dot as primary cursor
- Outer ring following with delay effect
- **Hover States**:
  - Expands on buttons
  - Color shifts on links
  - Dynamic reactions throughout experience

### 3. Services Section
- Display as animated tech cards/modules (not basic cards)
- **Six Services** (each with hover video, not static images):
  1. Ambient Lighting (3D printed lamps)
  2. Table Lamps & Home Décor
  3. Custom Keychains & Accessories
  4. Aerospace/Educational Display Models
  5. Hackathon & Startup Prototypes
  6. Statues & Artistic Prints
- Subtle glow effects and motion on each card

### 4. How It Works (Interactive)
- 3-step animated flow with scroll-triggered reveals:
  1. Share your idea/design
  2. Get instant quote on WhatsApp
  3. We print & deliver
- Steps animate progressively on scroll

### 5. Showcase/Gallery
- Grid layout featuring short looping videos (not photos)
- Hover interaction: scale + glow effect
- Showcases real work examples

### 6. Why Choose Spectra
- Animated icons/SVGs for each benefit
- **Key Points**:
  - High precision prints
  - Fast turnaround
  - Startup & student friendly
  - Affordable pricing
  - Modern materials

### 7. CTA Conversion Section
- Bold headline: "Have an idea? Let's print it."
- WhatsApp button with pre-filled message template:
  *"Hi Spectra 3D Hub 👋 I want a quote for 3D printing."*
- High-impact conversion focus

### 8. Footer
- Minimal, clean tech-style design
- Brand name
- Instagram: @spectra_3d_hub
- Phone: +91 6385444407
- Subtle, unobtrusive styling

## Typography
- Bold, modern sans-serif for headlines
- Clean, readable fonts for body text
- Hierarchy emphasizing tech/precision aesthetic

## Interactions & Animations (Mandatory)
- Smooth scrolling throughout
- Scroll-triggered animations (fade, slide, reveal)
- Hover micro-interactions on all interactive elements
- Magnetic hover effect on buttons
- Seamless section transitions
- All animations using GSAP or AOS library

## Responsive Behavior
- Desktop: Full immersive experience
- Tablet: Adapted grid layouts, maintained animations
- Mobile: Stacked sections, optimized touch interactions
- Custom cursor only on desktop (standard on mobile)

## Video Integration
- Hero background: Looping tech/3D printing footage
- Service cards: Hover-activated video previews
- Gallery: Short looping video clips
- All videos muted, optimized for web

## Key Design Principles
- **No placeholders**: Real content only
- **Startup-grade UI**: Professional, polished, production-ready
- **Tech aesthetic**: Glowing accents, precise borders, futuristic feel
- **Depth**: Layered design with subtle shadows and glows
- **Motion**: Purposeful animations enhancing the tech narrative
